# 🎵 Pattu

Pattu is a modern music player built with React, focused on delivering a clean and intuitive music listening experience.

## Features

* Create and manage playlists
* Responsive user interface
* Fast and simple navigation

## Live Demo

[View Live Demo - Pattu](https://pattu-nine.vercel.app/)


## Tech Stack

* React
* React Router
* CSS
* JavaScript

## Running Locally

```bash
git clone https://github.com/sarathkpreman/music-player.git

cd pattu

npm install

npm run dev
```

## Status

🚧 Currently under active development.

New features and improvements are being added.

## Note
